# Tableau Dashboards

A small collection of early Tableau dashboard projects.

These dashboards are beginner Tableau work, but they show the foundation of my data-visualization practice: cleaning data, shaping it for analysis, choosing a small set of useful questions, and building readable dashboards.

## Projects

### Chinook Music Market

A music-store dashboard built from the Chinook database and track data. It explores sales by country, genre, artist, quantity, and revenue.

Folder: `Music Market/`

### Streaming Platforms

A platform-catalog dashboard comparing Amazon Prime, Disney+, and Netflix title data. A Pandas notebook reshapes cast, director, genre, country, platform, and show records into Tableau-ready CSV files.

Folder: `plat forms'/`

### YouTube Trending Videos

A YouTube trends dashboard built from cleaned video data, category labels, and transposed tag records. It explores views, categories, channels, states, likes, dislikes, comments, and tags.

Folder: `youtube/`

## Notes

The repository includes packaged Tableau workbooks (`.twbx`) and supporting datasets so the dashboards can be opened locally in Tableau.
